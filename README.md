## 🚀 How to Run

1. Clone the repository
```bash
git clone https://github.com/yourusername/Python-Basic-Projects.git
```

2. Navigate to any project folder
```bash
cd Projects
```

3. Run any project
```bash
python project_name.py
```

4. Some projects require additional libraries — install with:
```bash
pip install PyQt5 pygame requests
```
